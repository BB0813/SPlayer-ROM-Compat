# Beta91 Android 播放页双端排版修正方案

## 背景

Beta90 已将卡片式播放默认切回 Web 底部卡片，并补充横滑切歌、上滑展开。新的截图显示全屏播放页仍存在两个体验问题：横屏/平板布局过于分散，封面、信息、控制区没有形成稳定分栏；竖屏手机下“左滑查看歌词”和分页点会压到播放控制按钮附近。

## 目标

- 横屏和平板播放页改为更稳定的左右分栏：封面在左，歌曲信息、进度条和控制区在右。
- 竖屏播放页把提示胶囊和分页点上移，避免遮挡播放/暂停按钮。
- 控制区保持 44px 以上触控尺寸，不牺牲可点性。
- 不改播放逻辑，只修复排版和交互层级。

## 实施范围

1. 增加 Android 横屏播放页分栏样式。
2. 限制横屏封面大小和内容宽度，减少空白漂移。
3. 调整竖屏提示胶囊、分页点位置和透明度。
4. 对低高度设备进一步压缩封面与间距。
5. 更新版本号、README 与双设备基础验证。
