# Beta92 Android 播放页纵向锁定方案

## 问题

- 全屏播放页当前可以上下拖动。
- 歌曲信息页使用 `overflow-y: auto` 与 `touch-action: pan-y`，在 Android WebView 中会触发页面纵向滚动和橡皮筋位移。
- 需要保留左右滑到歌词页、进度条拖动、歌词页内部纵向滚动。

## 实现

- 播放页根容器使用 `overscroll-behavior: none`，阻断外层滚动链。
- 歌曲信息页改为固定视口布局，禁用纵向滚动。
- 仅歌词页内容继续允许纵向滚动。
- 使用 `max-height` 与压缩间距适配低高度设备，避免因为内容超出再打开整页滚动。

## 验证

- 手机端播放页不能上下拖动。
- 手机端仍可左右滑到歌词页。
- 歌词页仍可纵向查看歌词。
- 平板端播放页不出现上下橡皮筋位移。
