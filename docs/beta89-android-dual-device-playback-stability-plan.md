# Beta89 Android 双设备播放稳态优化方案

## 背景

Beta88 已暂停播放中的文本跑马灯和部分装饰动画。下一阶段需要继续降低手机和平板播放时的 WebView 合成压力，并用两台虚拟机建立基础验证结果。

## 目标

- 播放中继续降低列表、卡片、封面和搜索遮罩的绘制成本。
- 不隐藏页面、不冻结路由、不调整主布局结构。
- 手机和平板均完成安装、启动和基础日志检查。
- 保持当前原生底部播放卡片与原生媒体控制逻辑不变。

## 实施范围

1. 播放中降低卡片、封面、搜索框、底部栏和播放条阴影。
2. 播放中给列表项、封面项、设置项增加轻量渲染隔离。
3. 播放中关闭封面图片 hover/filter/transform 类额外合成。
4. 更新版本号与 README 到 `3.0.0-rc.3-Beta89`。
5. 构建三架构 APK，并对手机、平板虚拟机做 ADB 基础验证。

## 风险控制

- 不使用 `display: none` 处理主内容。
- 不恢复路由冻结开关。
- 只在 `android-playback-active` 状态下降低视觉成本，未播放时保留原效果。

## 验证项

- `pnpm format`
- `pnpm lint`
- `pnpm build`
- `pnpm android:apk:all`
- 手机 `192.168.1.128:5555` 安装启动检查
- 平板 `192.168.1.167:5555` 安装启动检查
