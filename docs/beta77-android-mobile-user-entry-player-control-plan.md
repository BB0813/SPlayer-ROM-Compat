# Beta77 Android 顶部用户入口与播放控制前置修复

## 目标

- 修复测试用户反馈的顶部用户入口消失问题。
- 确保发布目录和开发目录的移动端顶栏实现一致。
- 为下一阶段播放页与底部播放控制原生化保留稳定布局基线。

## 问题定位

开发目录中的 `Nav.vue` 已包含移动端 `User compact` 入口，但提交目录未同步该文件，导致发布包顶部只剩搜索框、设置按钮和菜单按钮。与此同时，搜索框使用固定宽度预留，后续加入用户入口后在窄屏上仍有被挤压或覆盖的风险。

## 本阶段改动

- 同步并强化移动端 `mobile-user-entry` 渲染。
- 给顶部动作区增加 `--mobile-nav-action-reserve` 变量。
- 搜索框宽度改为读取动作区预留变量。
- 顶部动作区提高层级，避免被搜索框遮挡。
- README 更新到 `v3.0.0-rc.3-Beta77`。

## 下一阶段

Beta78 建议开始处理播放页和底部播放控制：优先把播放状态展示、播放/暂停、上一首、下一首、进度条区域从 Web 高刷新链路中拆出来，减少播放时首页和歌词页卡顿。
