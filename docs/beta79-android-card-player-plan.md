# Beta79 Android 卡片式播放与迷你播放控件计划

## 目标

- 将用户反馈的卡片式播放纳入 Android 长期开发计划。
- 先把底部迷你播放器改成更接近原生移动端的卡片结构。
- 提升播放卡片的触控可用性，让用户更容易进入播放页和控制音乐。
- 为后续底部播放控件半原生化保留稳定布局基线。

## 用户反馈

- 测试用户认为卡片式播放实用，可以作为移动端播放体验方向。
- 当前底部播放器虽然功能可用，但视觉上更像传统底栏，和移动端卡片化交互还有差距。
- 播放时首页、歌单页、设置页仍可能受到播放状态刷新影响，需要继续把播放控制从普通页面流中剥离。

## 本阶段改动

- Android 移动端底部播放器改为悬浮卡片样式，和底部导航形成上下两个独立 Dock。
- 播放卡片保留封面、歌名、播放/暂停、上一首、下一首等核心操作。
- 播放卡片增加整卡点击入口，点击非控制区域可进入原生播放页。
- 进度条收进卡片内部顶部，避免外溢造成安全区和边距观感问题。
- Android 播放减负模式下卡片禁用重阴影和多余过渡，降低播放时渲染压力。

## 后续计划

- Beta80 继续拆分底部播放控制状态，减少首页、歌单页、设置页的无关刷新。
- Beta81 评估将底部迷你播放器下沉到 Android 原生 View。
- Beta82 继续补齐卡片式播放的横屏和平板专用排版。
