# Beta86 Android ROM 媒体控制状态一致性计划

## 目标

- 优化国内 ROM 上增强通知卡片的播放/暂停状态一致性。
- 降低 ColorOS、HarmonyOS Connect 等环境中切歌后通知卡片状态丢失的概率。
- 保持原生 ROM 媒体控制卡片优先，增强卡片仅作为 ROM 兼容补充。
- 修复 Android 原生媒体按钮与增强通知通道里的中文乱码。

## 本阶段改动

- 增强通知卡片播放中改为常驻，避免部分 ROM 在切歌或状态刷新间隙回收卡片。
- ROM 控制动作触发后，增强通知卡片增加多段延迟刷新，覆盖 Web 侧异步切歌和元数据回填耗时。
- 原生媒体通知继续保留二段刷新，和增强卡片刷新节奏分离。
- 修复 MediaSession 上一首、下一首按钮文案乱码。
- 修复增强通知通道名称和描述乱码。

## 验证重点

- 开启第三方 ROM 增强通知卡片后，播放/暂停图标与软件内状态一致。
- 开启增强通知卡片后点击上一首、下一首，卡片不应消失。
- ColorOS / HarmonyOS Connect 上控制动作后 1 到 2 秒内状态应自动回正。
- 未开启增强通知卡片时，原生 ROM 音频控制卡片不受影响。
- Android Kotlin 编译通过。

## 后续计划

- Beta88 继续压缩 WebView 播放中页面动态组件负载。
- Beta89 评估原生歌词页逐字状态的低频同步策略。
