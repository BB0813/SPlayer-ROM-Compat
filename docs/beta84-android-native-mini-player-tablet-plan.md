# Beta84 Android 原生底部卡片平板自适应计划

## 目标

- 优化原生底部播放卡片在手机、折叠屏和平板横屏下的宽度与间距。
- 避免平板横屏时播放卡片横向铺满导致控件分散、点击区域不稳定。
- 修复 Beta83 原生卡片内少量中文文案乱码。
- 保持进度刷新与拖拽仍由原生层处理，不恢复高频 Web Bridge 同步。

## 本阶段改动

- 根据 `screenWidthDp` 自动判断宽屏设备。
- 手机端继续使用贴近底部导航的全宽卡片。
- 宽屏设备将原生底部卡片限制为居中中等宽度，降低横向割裂感。
- 宽屏设备略微增加卡片高度、封面尺寸和左右内边距。
- 修复播放进度、准备播放、未知歌手、上一首、播放、暂停、缓冲、下一首、队列等中文显示。
- 在 View 尺寸变化时重新应用布局，覆盖平板横竖屏切换场景。

## 验证重点

- 手机端底部播放卡片不被导航栏裁切。
- 平板横屏底部播放卡片不再横向铺满全屏。
- 上一首、播放暂停、下一首、队列和进度拖拽仍可用。
- 播放进度更新仍由原生 `progressTicker` 承担。
- 原生卡片内中文文案不再出现乱码。

## 后续计划

- Beta85 继续评估歌词页状态下沉到原生层。
- Beta86 继续处理国内 ROM 媒体控制状态一致性。
- Beta87 评估播放队列列表的原生化入口与轻量展示。
