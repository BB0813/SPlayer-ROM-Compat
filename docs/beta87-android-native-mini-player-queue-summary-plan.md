# Beta87 Android 原生底部卡片队列摘要计划

## 目标

- 提升原生底部播放卡片的队列入口可用性。
- 在不重写完整队列列表的前提下，让用户能直接看到当前队列位置。
- 减少播放中打开 Web 队列弹层前的判断成本。
- 保持原生底部播放卡片仍然只接收低频稳定状态，不恢复进度高频同步。

## 本阶段改动

- 原生底部播放卡片状态新增 `queue` 字段。
- Web 侧从 `dataStore.playList` 与 `statusStore.playIndex` 构建队列摘要。
- 原生“队列”按钮在有队列时显示 `当前/总数`，无队列时显示“队列”。
- 原生“队列”按钮增加可访问描述，提示当前播放位置。
- 播放队列数量或当前索引变化时触发原生底部卡片稳定状态同步。

## 验证重点

- 播放列表中有歌曲时，原生底部卡片显示类似 `3/12`。
- 无播放队列或队列为空时，按钮显示“队列”。
- 点击队列按钮仍能打开或关闭 Web 播放队列。
- 播放进度变化仍不会触发完整原生卡片同步。
- Android Kotlin 编译通过。
