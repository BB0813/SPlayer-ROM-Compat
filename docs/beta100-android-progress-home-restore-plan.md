# Beta100 Android 播放状态条与主页恢复修复计划

## 背景

测试反馈底部播放状态条仍然带有背景轨道，且进度条位置不符合当前卡片式底部播放器设计。播放中点回主页时，部分设备会出现主页内容区黑屏，只保留顶部与底部固定控件。

## 目标

- 播放状态条不再显示灰色轨道背景。
- 进度线不再压在卡片顶部，改为贴近播放器底边显示。
- 首页返回时保持稳定可见，不因旧配置或播放轻量模式出现空白黑屏。
- 不增加底部固定区域高度，避免重新引入底部蓝框感。

## 实现

- `MainPlayer.vue` 隐藏 Android 轻量进度条轨道伪元素，仅保留已播放进度线。
- `MainPlayer.vue` 将底部播放器进度线固定到卡片内侧底边，普通进度组件同步透明轨道。
- `HomeOnline.vue` 为首页推荐分区增加配置兜底，当设置项为空时回退到默认推荐分区。
- `Home/index.vue` 与全局 Android 样式增加首页根容器最小高度和可见性保护。

## 验证重点

- 播放中观察底部播放器是否仍有灰色背景轨道。
- 播放中从其他页面点回主页，确认首页不黑屏。
- 手机和平板都确认底部固定区域没有重新变厚。
- 歌单、发现、设置等页面切换时不出现新的横向拖动或空白。
