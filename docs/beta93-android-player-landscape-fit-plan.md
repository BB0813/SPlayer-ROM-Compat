# Beta93 Android 播放页横屏内容完整显示方案

## 问题

- Beta92 锁定播放页纵向拖动后，横屏设备上内容不能再通过上下拖动补偿。
- 部分虚拟机或 ROM 横屏时没有稳定命中 `android-landscape` 根类，导致播放页仍使用竖屏纵向排布。
- 结果是封面占用上半屏，歌曲信息和进度条挤在下方，播放控制区被裁切。

## 实现

- 增加 `@media (orientation: landscape)` 兜底规则，只要 Android WebView 处于横屏就启用双栏播放页。
- 横屏下取消信息区 `42svh` 高度限制，改为完整控制区可见。
- 横屏下压缩封面、按钮、进度条和提示点间距，保证 720p 高度也能放下。
- 继续保留 Beta92 的纵向锁定，不恢复整页上下拖动。

## 验证

- 横屏播放页必须完整显示封面、歌曲信息、进度条和播放控制区。
- 播放页信息页不能上下拖动。
- 左右滑动歌词页仍可用。
