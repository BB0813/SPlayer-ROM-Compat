# Beta65 Android 平板密度与歌词手势修复方案

## 目标

- 优化 Android 平板横屏、竖屏与高 DPI 设备上的内容宽度、卡片密度和歌单详情排版。
- 修复歌词页横滑与纵向滚动互相抢手势的问题。
- 保持手机端自适应和底部播放栏修复不回退。

## 根因

- 目前只有 `android-tablet-layout` 与 `android-landscape` 两个粗粒度 class，样式无法区分平板横屏、平板竖屏和高 DPI 平板。
- 部分首页、封面列表、歌单详情样式仍按手机或桌面宽度自然拉伸，导致平板上内容密度不稳定。
- 歌词主体区域曾尝试保留纵向滚动，但 `touch-action: pan-y` 会让从歌词区起手的横滑更容易失效。

## 实现

- 为 Android 根节点补充 `android-tablet-landscape`、`android-tablet-portrait`、`android-wide-layout`、`android-hidpi-tablet` class。
- 为平板布局增加居中内容宽度、横竖屏不同边距、封面网格密度、歌单详情横向排版兜底。
- 歌词页统一允许横纵触摸，由组件手势逻辑决定横滑切页或纵向滚动。
- 将版本号更新到 `3.0.0-rc.3-Beta65`。

## 验证重点

- 平板横屏首页、发现页、歌单详情不再过度拉伸或挤压。
- 全屏播放页从封面页左滑进入歌词页、从歌词页右滑返回均可用。
- 歌词页纵向滚动不被横滑逻辑误拦截。
- 手机竖屏布局、底部导航栏和播放小窗不回退。
