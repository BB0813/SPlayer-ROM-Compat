# Beta70 Android 平板歌单页排版收敛计划

## 背景

Beta69 修复了平板歌单歌曲列表空白问题，但实测截图仍存在详情头部被顶出视口、详情区与列表区之间空白过大、列表首项贴近底部导航的问题。当前问题更像是父级滚动位置、旧顶部内边距、详情头固定高度三者叠加导致的平板端排版漂移。

## 目标

- 平板横屏歌单详情页首屏稳定显示封面、标题、按钮和列表表头。
- 详情区与歌曲列表之间保留小间距，不再出现大面积空白。
- 列表区域拥有明确的最小高度，首项不被底部导航遮挡。
- 打开右上角菜单时不影响页面布局测量。

## 实现

- 平板歌单页采用更紧凑的详情头高度与封面尺寸。
- 歌单页根容器禁止承载纵向滚动，交给虚拟歌曲列表内部滚动。
- 平板歌单页的歌曲列表清理旧 padding，并设置明确的 flex 高度与底部安全避让。
- 进入歌单页或切换歌单时主动重置滚动位置，避免沿用上一次页面滚动偏移。

## 验证

- 运行 `pnpm format`。
- 运行 `pnpm lint`。
- 运行 `pnpm build`。
- 构建 `x86_64` APK，安装到手机与平板虚拟机。
- 检查平板横屏歌单页：详情头完整、列表表头与首项可见、底部导航不裁切。
