# Beta76 Android 移动端设计令牌统一计划

## 目标

- 不再按单个页面反复补丁式调间距，先建立 Android 端统一设计令牌。
- 统一手机和平板的字号、间距、圆角、阴影、触控高度、底部播放栏和底部导航高度。
- 缓解测试用户反馈的“点不舒服”“界面乱”“控件大小和间隔不统一”等问题。

## 实现范围

- `App.vue`：调整自动 UI 缩放策略，避免手机端默认过度压缩。
- `src/style/main.scss`：新增 Android 字号、间距、圆角、阴影、触控和底部 Dock 令牌。
- `MobileTabBar.vue`：底部导航接入统一高度、圆角、阴影和标签字号。
- `AppLayout.vue`：窄屏底部 Dock 变量接入统一令牌。
- `README.md`：记录 Beta76 更新内容。

## 设计基线

- 常规文字不低于 `15px`。
- 主要触控目标不低于 `44px`。
- 底部播放和导航控件使用同一套 Dock 高度变量。
- 搜索框和底部导航阴影弱化，减少移动端压迫感。
- 平板端增加内容边距和字号上限，避免低 DPI 或窄宽平板显得拥挤。

## 与全原生化关系

本阶段仍是 WebView 内的 UI 基线治理，目标是让现有版本先稳定可测。全原生化仍建议从播放页和底部控制开始，因为那部分最容易受播放状态刷新、歌词滚动和系统手势影响。
