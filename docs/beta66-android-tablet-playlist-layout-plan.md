# Beta66 Android 平板歌单页排版修复方案

## 目标

- 修复平板横屏歌单详情头部仍然过高的问题。
- 修复列表区域被挤到底部、首行歌曲被底部播放栏压住的问题。
- 收紧平板歌单页横向宽度和列表行宽，避免出现横向溢出或异常长条。

## 根因

- `ListDetail.vue` 内部仍有固定 `height: 240px`，Beta65 只覆盖了 `min-height`，没有覆盖 `height`。
- `useListDetail()` 计算列表高度时仍按桌面详情头部 `240px` 扣减，和 Android 平板横屏的目标紧凑头部不一致。
- 平板横屏下歌单页面没有单独限制 `playlist-list`、`song-list` 和虚拟列表内部宽度，极端宽高比例下更容易出现横向溢出。

## 实现

- 增加 Android 平板横屏详情头部高度变量，统一 CSS 高度与 JS 列表高度计算。
- 平板横屏下把歌单详情头部压缩到约 156px，滚动后压缩到约 104px。
- 平板竖屏保留更舒展的详情头部，但不再使用桌面 240px 固定高度。
- 给歌单容器、歌曲列表、虚拟列表容器增加横向溢出保护。
- 将版本号更新到 `3.0.0-rc.3-Beta66`。

## 验证重点

- 平板横屏进入歌单页后，列表首屏应能直接看到更多歌曲。
- 当前播放歌曲行不应被底部播放栏遮挡。
- 页面不能左右拖出横向空白或出现异常长条。
- 手机竖屏与普通手机布局不回退。
