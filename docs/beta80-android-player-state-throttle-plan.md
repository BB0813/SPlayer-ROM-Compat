# Beta80 Android 播放状态刷新减负计划

## 目标

- 降低 Android 播放时底部播放卡片的渲染压力。
- 减少首页、歌单页、设置页被播放进度状态带动刷新的概率。
- 保留底部播放卡片的核心播放控制，避免为了性能牺牲基础操作。
- 为后续底部播放控件原生化继续拆分状态边界。

## 用户反馈

- 播放音乐后，首页、歌单页、设置页仍有明显卡顿。
- 底部播放卡片虽然更符合移动端习惯，但播放状态刷新仍会牵动较多组件。
- 测试用户更关注封面、歌名、上一首、播放/暂停、下一首等核心控制，底栏歌词和复杂菜单可先让位给性能。

## 本阶段改动

- Android 性能模式下底部播放卡片改用轻量进度条，不再渲染 Naive UI Slider。
- Android 性能模式下底部播放卡片不再渲染底栏歌词动画。
- Android 性能模式下底部播放卡片不再渲染右侧时间和播放队列菜单。
- 底部播放卡片保留封面、歌名、上一首、播放/暂停、下一首等核心控制。
- 修复卡片化后上一首、下一首按钮在移动端样式中被隐藏的问题。
- Android 性能模式下播放进度刷新间隔调整为 1500ms，降低播放时全局状态更新频率。

## 验证重点

- 播放时首页、歌单页、设置页是否比 Beta79 更稳定。
- 底部播放卡片核心控制是否仍可正常点击。
- 播放进度视觉是否连续，且不会明显拖慢页面。
- 打开完整播放页后，歌词和播放页核心交互是否不受底栏轻量化影响。

## 后续计划

- Beta81 继续评估底部播放卡片原生 View 化，减少 WebView 常驻渲染压力。
- Beta82 继续拆分播放页歌词渲染和普通页面状态，避免歌词动效影响其他页面。
- Beta83 继续补齐平板端卡片式播放和横屏布局。
