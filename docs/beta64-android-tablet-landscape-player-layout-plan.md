# Beta64 Android 平板横屏播放布局修复方案

## 目标

- 修复平板横屏下底部播放器与底部导航栏重叠的问题。
- 恢复全屏播放页左右滑动到歌词页的手势。
- 保持手机端现有底部布局和缩放逻辑不回退。

## 根因

- 底部播放器避让导航栏的样式只写在 `max-width: 768px` 中，横屏平板宽度超过该阈值后不生效。
- 全屏播放页根节点使用 `touch-action: pan-y`，浏览器会优先按纵向滚动处理，横向滑动不稳定。
- 平板横屏依旧使用移动底部导航栏，因此需要 Android 专用兜底规则，而不是继续依赖宽度媒体查询。

## 实现

- 在 Android 环境下统一让带底部导航的播放器抬高到导航栏上方。
- 在 Android 平板横屏下压缩底部播放器为移动端两列布局，隐藏右侧菜单，避免横屏宽度误用桌面播放器布局。
- 将全屏播放页根节点改为允许横纵手势，歌词主体保留纵向滚动。
- 将版本号更新到 `3.0.0-rc.3-Beta64`。

## 验证重点

- 横屏平板底部导航栏不再盖住播放小窗。
- 从播放信息页可左右滑动进入歌词页，再滑回信息页。
- 歌词页纵向滚动仍可使用。
- 手机竖屏底部布局不回退。
